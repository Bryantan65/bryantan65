#### Autonomous ML research agent · TikTok TechJam 2026
An LLM agent that improves a video recommender with zero human interventions: it forms a hypothesis, writes a solution, gets it scored, and decides what to try next. It beat the official baseline on both benchmarks. I built the harness, experiment ledger and code-enforced guardrails.

#### Aegis: multi-agent operations for town councils · Hack For Cities 2026 (2nd of 40+)
Five IBM watsonx agents that triage resident complaints, cluster duplicates into hotspots, plan field-team run sheets and verify completed work with photo evidence. Built with React, TypeScript, Supabase and a Telegram bot.

#### StudyBuddy · Tech4City 2026
Circle a question on your own notes and get a correct, interactive 3D visual of it. GPT-4o vision routes each question to pre-verified templates instead of generating geometry live, because a plausible but wrong diagram is worse than none. Built with React, react-three-fiber and FastAPI.
